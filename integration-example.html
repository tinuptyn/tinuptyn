🚀 集成方式

方式一：iframe嵌入（推荐）

最简单的方式，直接在您的页面中嵌入：

<iframe src="weather-widget.html"
width="100%"
height="800px"
frameborder="0"
style="border-radius: 15px;">
</iframe>

方式二：直接复制代码

将组件的HTML、CSS和JavaScript代码复制到您的项目中。

方式三：作为Web组件

封装为自定义Web Component，实现真正的组件化。

<weather-widget city="Beijing"></weather-widget>

⚙️ 配置说明

步骤1： 前往 OpenWeatherMap 注册并获取免费API密钥

步骤2： 在 weather-widget.html 中替换 API_KEY

const API_KEY = 'YOUR_API_KEY_HERE'; // 替换为您的密钥

步骤3： 保存并刷新页面，即可使用真实的天气数据
